# ロバスト性・テスト網羅性の広範な検証 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** cl-mcp のテストカバレッジを実測できるローカル基盤を作り、その数値を入力としてロバスト性監査を実施し、優先度付きの所見レポートを残す。

**Architecture:** 4 つの部品を一方向依存で分ける。(1) `scripts/coverage.ros` が src を sb-cover で計装して全スイートを回し数値を出す、(2) `scripts/coverage-scope.md` が計測できない領域を理由付きで列挙する、(3) `comprehensive-test` スキルが (1)(2) の出力を入力に 2 観点で監査する、(4) 統合レポートが所見に「カバレッジ上の位置づけ」を付ける。

**Tech Stack:** SBCL 2.5.8 / sb-cover / Roswell (`ros`) / ASDF package-inferred-system / Rove / `comprehensive-test` スキル

**設計仕様:** `docs/superpowers/specs/2026-08-01-robustness-and-coverage-audit-design.md`

## Global Constraints

- 対象は SBCL のみ（cl-mcp は SBCL 専用プロジェクト）。他処理系への配慮は不要
- **カバレッジ計測は親プロセスのみ。** ワーカー子プロセス内の実行は計測しない
- **CI には載せない。** ローカル実行スクリプトのみ
- **計測の都合で本番の品質ゲート（テストの閾値など）を緩めてはならない。** 落ちたテストは記録して除外扱いにする
- **カバレッジ 0% を黙って返してはならない。** sb-cover の内部 API が期待と違えば明示的にエラーを投げる
- Lisp ソースの編集は `lisp-edit-form` / `lisp-patch-form` を使う（テキスト編集ツールは括弧を壊す）。ただし `scripts/coverage.ros` は ASDF システム外の新規スクリプトなので `Write` で作成してよい

```lisp
#!/bin/sh
#|-*- mode:lisp -*-|#
#|
exec ros -Q -- $0 "$@"
|#
(progn ;;init forms
  (ros:ensure-asdf)
  (require :sb-posix)
  (require :sb-cover)
  #+quicklisp (ql:quickload '(:rove) :silent t))

(defpackage :ros.script.coverage
  (:use :cl))
(in-package :ros.script.coverage)

;;; cl-mcp のテストカバレッジを sb-cover で実測するドライバ。
;;;
;;; 使い方（リポジトリのルートから実行する）:
;;;   ./scripts/coverage.ros --smoke   既知の答えで計測パイプラインを検算する（約2分）
;;;   ./scripts/coverage.ros           全スイートを計装実行する（12〜18分）
;;;
;;; ワーカー子プロセス内の実行は計測できない。盲点は scripts/coverage-scope.md を見ること。

(defun repo-root ()
  "カレントディレクトリをリポジトリのルートとして返す。ルートでなければエラーにする。"
  (let ((cwd (uiop:getcwd)))
    (unless (probe-file (merge-pathnames "cl-mcp.asd" cwd))
      (error "cl-mcp.asd が見つからない。リポジトリのルートから実行すること（現在: ~A）" cwd))
    cwd))

(defun setup-isolated-cache (root)
  "計装済み fasl を専用ディレクトリに隔離し、そのディレクトリを返す。

環境変数も設定するのは、ワーカー子プロセスが親の環境を引き継いで同じキャッシュを
読むようにするためである。ワーカー側のカバレッジは捨てるので数値には影響しないが、
通常のキャッシュを計装済み fasl で汚さないことが目的である。"
  (let ((cache (merge-pathnames "coverage/cache/" root)))
    (ensure-directories-exist cache)
    (sb-posix:putenv (format nil "ASDF_OUTPUT_TRANSLATIONS=/:~A" (namestring cache)))
    (asdf:initialize-output-translations)
    cache))

(defun main (&rest argv)
  (declare (ignorable argv))
  (let* ((root (repo-root))
         (cache (setup-isolated-cache root)))
    (format t "~&repo-root: ~A~%cache:     ~A~%" root cache)
    (format t "~&translated: ~A~%"
            (asdf:apply-output-translations
             (merge-pathnames "src/utils/strings.lisp" root)))
    (uiop:quit 0)))
```

```lisp
(defun collect-file-coverage (file)
  "FILE の (式ok 式all 分岐ok 分岐all) を返す。

sb-cover は HTML しか出さないので、HTML を書き出す関数に空ストリームを渡して
数値だけを取り出す。sb-cover 自身の集計ロジックを再利用するため、ここで得た数値は
HTML レポートの数字と必ず一致する。"
  (let ((counts (sb-cover::report-file file (make-broadcast-stream) :default)))
    (unless (and (listp counts) (= 2 (length counts)))
      (error 'coverage-adapter-error
             :detail (format nil "report-file が 2 要素のリストを返さなかった: ~S" counts)))
    (destructuring-bind (expression branch) counts
      (list (sb-cover::ok-of expression) (sb-cover::all-of expression)
            (sb-cover::ok-of branch) (sb-cover::all-of branch)))))
```

- [ ] **Step 2: 検算を走らせて、期待値と食い違うことを確認する**

```bash

```

期待: `SMOKE FAILED` かつ `actual (22 32 4 6)`。

読み方に注意する。**式 ok は 21 のままではなく 22 に増える。** sb-cover はトップレベルフォーム
そのものも計装対象にし、`(defun ...)` フォーム自体はファイルのロード時に必ず実行されるためである
（SBCL の `ir1tran.lisp` の `ir1-convert` がマクロ展開前の生フォームに対して
`instrument-coverage` を無条件に呼ぶ）。増えた 11 式のうち実行されたのはこの 1 つだけで、
関数の本体（`if`、`evenp`、2 つの `format`）はすべて未実行のままである。

分岐は予想どおり `ok` が 4 で据え置き、`all` だけが 6 に増える。

**判定基準**: 追加した関数の**本体**が未カバーとして数えられていること。式の増分 11 に対して
実行済みの増分が 1（トップレベルフォーム分）であること、そして分岐 ok が動かないことの 2 点で確認する。
もし `ok` と `all` が同じだけ増えたなら、計測が実行の有無を見ていないので**先に進んではならない**。

- [ ] **Step 1: フル実行とサマリ出力を実装する**

`run-smoke` の後ろに以下を挿入する:

```lisp
(defun test-package-names ()
  "cl-mcp/tests が依存するテストパッケージ名の一覧を返す。

tests.lisp の test-op フックと同じ選び方をしている。テストを 1 つ追加したときに
ここだけ更新し忘れる事故を防ぐため、一覧をハードコードしない。"
  (remove-if-not (lambda (dependency)
                   (and (stringp dependency)
                        (uiop:string-prefix-p "cl-mcp/tests/" dependency)))
                 (asdf:system-depends-on (asdf:find-system :cl-mcp/tests))))

(defun percentage (ok all)
  (if (zerop all) 0.0 (* 100.0 (/ ok all))))

(defun source-relative-name (file root)
  "FILE がリポジトリ配下なら相対パス、そうでなければ絶対パスの文字列を返す。"
  (let ((root-string (namestring root))
        (file-string (namestring file)))
    (if (uiop:string-prefix-p root-string file-string)
        (subseq file-string (length root-string))
        file-string)))

(defun summary-rows (root)
  "(相対パス 式ok 式all 分岐ok 分岐all) をカバレッジ率の低い順に返す。"
  (let ((rows '()))
    (maphash (lambda (file records)
               (declare (ignore records))
               (when (probe-file file)
                 (let ((name (source-relative-name file root)))
                   (when (uiop:string-prefix-p "src/" name)
                     (push (cons name (collect-file-coverage file)) rows)))))
             (coverage-table))
    (sort rows #'< :key (lambda (row) (percentage (second row) (third row))))))

(defun write-summary (root rows)
  "ROWS を docs/coverage-summary.md に書き出す。"
  (let ((path (merge-pathnames "docs/coverage-summary.md" root))
        (total-expression-ok 0) (total-expression-all 0)
        (total-branch-ok 0) (total-branch-all 0))
    (dolist (row rows)
      (destructuring-bind (name expression-ok expression-all branch-ok branch-all) row
        (declare (ignore name))
        (incf total-expression-ok expression-ok)
        (incf total-expression-all expression-all)
        (incf total-branch-ok branch-ok)
        (incf total-branch-all branch-all)))
    (with-open-file (stream path :direction :output
                                 :if-exists :supersede
                                 :if-does-not-exist :create)
      (format stream "# カバレッジサマリ~%~%")
      (format stream "`scripts/coverage.ros` が生成する。手で編集しないこと。~%~%")
      (format stream "- SBCL: ~A~%" (lisp-implementation-version))
      (format stream "- 計測ファイル数: ~D~%" (length rows))
      (format stream "- 式カバレッジ合計: ~D/~D (~,1F%)~%"
              total-expression-ok total-expression-all
              (percentage total-expression-ok total-expression-all))
      (format stream "- 分岐カバレッジ合計: ~D/~D (~,1F%)~%~%"
              total-branch-ok total-branch-all
              (percentage total-branch-ok total-branch-all))
      (format stream "ワーカー子プロセス内の実行は計測できない。~
                      この表に出ない、あるいは 0% のファイルが未テストとは限らない。~
                      判断の前に `scripts/coverage-scope.md` を読むこと。~%~%")
      (format stream "| ファイル | 式 | 式% | 分岐 | 分岐% |~%")
      (format stream "|---|---|---|---|---|~%")
      (dolist (row rows)
        (destructuring-bind (name expression-ok expression-all branch-ok branch-all) row
          (format stream "| ~A | ~D/~D | ~,1F | ~D/~D | ~,1F |~%"
                  name expression-ok expression-all
                  (percentage expression-ok expression-all)
                  branch-ok branch-all
                  (percentage branch-ok branch-all))))
      (format stream "~%## 一度も実行されていないファイル~%~%")
      (let ((dead (remove-if-not (lambda (row) (zerop (second row))) rows)))
        (if dead
            (dolist (row dead)
              (format stream "- `~A` (式 0/~D)~%" (first row) (third row)))
            (format stream "なし。~%"))))
    path))

(defun cl-mcp-source-systems (root)
  "src/ 配下の .lisp ファイルに対応する ASDF システム名の一覧を返す。

package-inferred-system ではファイル 1 つがシステム 1 つに対応する。
`(asdf:load-system :cl-mcp :force t)` は **対象システムしか force せず、依存システムは
force しない** ので、src のほとんどはキャッシュ済み fasl が黙って再利用されてしまう。
計装したいシステムを名前で列挙して :force に渡す必要がある。"
  (let ((src (truename (merge-pathnames "src/" root))))
    (cons "cl-mcp/main"
          (sort (loop for path in (directory (merge-pathnames "**/*.lisp" src))
                      for relative = (enough-namestring path src)
                      collect (format nil "cl-mcp/src/~A"
                                      (subseq relative 0 (- (length relative)
                                                            (length ".lisp")))))
                #'string<))))

(defun clear-coverage-cache (cache)
  "計装キャッシュを空にする。

前回の実行が残した fasl を再利用すると、計装されているかどうかが実行ごとに変わり、
数値が再現しなくなる。計測は毎回まっさらから始める。"
  (when (probe-file cache)
    (uiop:delete-directory-tree cache :validate (constantly t)))
  (ensure-directories-exist cache))

(defparameter *third-party-dependencies*
  '("alexandria" "cl-ppcre" "yason" "usocket" "bordeaux-threads"
    "eclector" "hunchentoot")
  "cl-mcp.asd の :depends-on から cl-mcp/main を除いたもの。

これらは計装しない。third-party を計装しても数値には出ない
（summary-rows が src/ で絞る）一方、実行時間とメモリだけが膨らむ。")

(defun run-full (root cache)
  "src 全体を計装し、全テストスイートを回してサマリを書き出す。"
  (clear-coverage-cache cache)
  ;; 1. 依存ライブラリだけを計装なしでロードする。
  ;;
  ;;    ここで :cl-mcp 自体をロードしてはならない。cl-mcp のファイルが一度
  ;;    非計装でコンパイル・ロードされると、後の計装コンパイルの時点で
  ;;    パッケージも defvar も既に存在してしまい、定義系トップレベルフォーム
  ;;    （defpackage, in-package, declaim, defvar, defparameter, defclass,
  ;;    define-condition, defstruct）の初回定義経路が二度と実行されない。
  ;;    その結果それらが一律に未カバーとして数えられる。実測では約 323 フォーム、
  ;;    全体の 1.35% にあたるが、小さいファイルでは支配的になり、
  ;;    ロジックが 100% テストされている core.lisp が 33.3% と表示されていた。
  (dolist (system *third-party-dependencies*)
    (asdf:load-system system))
  ;; 2. 計装 ON にして cl-mcp 自身のシステムだけを強制再コンパイルする。
  (let ((systems (cl-mcp-source-systems root)))
    (proclaim '(optimize sb-cover:store-coverage-data))
    (asdf:load-system "cl-mcp" :force systems)
    ;; :cl-mcp の依存グラフから到達しないファイルを拾う。キャッシュは空なので
    ;; ここで初めてコンパイルされ、計装が乗る。
    (dolist (system systems)
      (asdf:load-system system))
    (proclaim '(optimize (sb-cover:store-coverage-data 0))))
  ;; ここで :force を付けてはならない。src が計装なしで再コンパイルされ、
  ;; 直前の計装が丸ごと無駄になる。
  (asdf:load-system :cl-mcp/tests)
  ;; テストが赤でも計測は続ける。赤いテストは監査の所見であって計測の失敗ではない。
  ;; 一方、計測そのものが例外で落ちたらサマリを書かずに終える。
  (handler-case (rove:run (test-package-names))
    (error (condition)
      (format *error-output* "~&テスト実行中に例外: ~A~%" condition)))
  (sb-cover:report (merge-pathnames "coverage/html/" root))
  (let ((rows (summary-rows root)))
    (when (null rows)
      (error 'coverage-adapter-error
             :detail "src 配下のファイルが 1 つも計測されていない"))
    (let ((path (write-summary root rows)))
      (format t "~&~%サマリ: ~A~%HTML:   ~A~%計測ファイル数: ~D~%"
              path (merge-pathnames "coverage/html/cover-index.html" root)
              (length rows))))
  0)
```

`main` の full 分岐を差し替える。`run-full` はキャッシュを空にするので `cache` を受け取る:

```lisp

           (t (run-full root cache)))
```
